CBT10 Backup

Herramienta interna de la 10ª Compañía, Cuerpo de Bomberos de Temuco, usada para respaldar de forma automática y cifrada la base de datos y documentos del sistema de inventario de la compañía hacia una carpeta privada de Google Drive.

Esta aplicación solo crea y administra archivos dentro de una carpeta propia que ella misma crea en Google Drive (permiso drive.file); no accede a ningún otro archivo de la cuenta.

Código fuente del sistema de inventario: github.com/janoski12/Inventariobomberos
